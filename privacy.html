Privacy Policy

Last updated: 27 October 2026

MrRajendraAutoYT ("the app") is a desktop application used only by the owner of the YouTube channel MrRajendravideos (channel ID UCI1Qp2Hgm3WdGGkOX0STOcA) to upload videos to that channel.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information the app accesses

  • The authenticated channel's ID, title and uploads playlist, used only to confirm that uploads go to the correct channel.
  • Status of videos uploaded by the app (for example privacy and processing status), used to confirm successful uploads.

The app uploads videos, titles, descriptions, tags and thumbnails that it creates itself. It does not read comments, subscribers, analytics, or any other user's data.

Storage

The OAuth refresh token is stored only on the owner's own computer in Windows Credential Manager. Job records (topic, title, video ID, status) are stored in a local database on the same computer.No data is sent to any server operated by the app developer, and no data is sold or shared with third parties.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions (see also Google security settings). Locally stored data can be deleted by removing the app folder and the "MrRajendraAutoYT" entry in Windows Credential Manager
